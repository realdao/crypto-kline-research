# BTC 底部检测策略

## 概述

基于三种技术信号识别 BTC 日线级别的底部，并对信号进行量化评估。数据来源：Binance API。

## 三大底部信号

### C1 — RSI 超卖

RSI(SMA, 14) < 30，即 14 日 SMA 相对强弱指标进入超卖区。

- 最佳阈值：RSI < 30（收紧到 28 可以提高胜率但减少信号数量）
- 信号特征：市场极度悲观，卖压耗尽
- **单独胜率：95%（3 月内最高收益为正）**
- 平均最高收益：+23.21%
- 最差回撤：-14.19%

### C2 — 巨量放量

当日成交量达到过去 2 年（730 日滑动窗口）的 95 百分位以上。

- 门槛：约 68,784 BTC（以 2023.06-2026.06 数据为基准）
- 信号特征：恐慌性抛售或主力吸筹，换手充分
- **单独胜率：100%**
- 平均最高收益：+30.34%
- 注意：2024 年牛市中纯 C2 信号较多（28 个），包含大量非底部放量

### C3 — RSI 底背离

在 90 日内，出现过 RSI < 35 的锚点，当前价格创出新低（局部最低），但 RSI 已经回升至 40 以上，且与锚点的 RSI 差距 ≥ 15。

- 信号特征：价格创新低但动能衰竭，是经典的底部背离形态
- **单独胜率：100%**
- 平均最高收益：+32.72%
- 注意：仅在局部价格最低点时触发，避免连续下跌中的假信号

## 信号组合评估

基于 2023-06-01 ~ 2026-06-03 数据（1,099 个交易日）：

| 组合 | 数量 | 平均最高收益 | 最差回撤 | 胜率 |
|------|------|-------------|----------|------|
| **C1 + C2** | 7 | **+28.44%** | **-7.10%** | **100%** |
| C1 | 41 | +23.21% | -14.19% | 95% |
| C2 | 28 | +30.34% | -4.49% | 100% |
| C3 | 6 | +32.72% | -13.95% | 100% |
| C1 + C2 + C3 | 1 | +34.65% | +7.24% | 100% |

**最佳组合：C1 + C2**（RSI 超卖 + 巨量）— 胜率 100%，平均最高收益 +28%，回撤可控。

## 收益衡量方式

不统计固定时间点的收盘价涨跌，而是统计：

- **3M_best**：信号出现后 90 日内的最高收盘价相对入场价的涨幅。代表最优逃顶收益。
- **3M_worst**：信号出现后 90 日内的最低点相对入场价的跌幅。代表最差承受的回撤。

## 经典案例

### ✅ 成功的底部信号

| 日期 | RSI | 成交量 | 条件 | 3M 最高 | 3M 最差 |
|------|-----|--------|------|---------|---------|
| 2024-08-05 | 26.66 | 162k (P99.8) | C1+C2 | **+34.65%** | +7.24% |
| 2026-02-05 | 15.82 | 106k (P99.3) | C1+C2 | **+29.47%** | -3.76% |
| 2023-08-17 | 21.05 | 100k (P97.4) | C1+C2 | **+42.20%** | -1.05% |
| 2025-04-07 | 38.37 | 78k (P95.4) | C2 | **+41.10%** | +0.15% |
| 2023-10-16 | 65.36 | 78k (P97.1) | C2 | **+64.74%** | +3.53% |

### ⚠️ 需要警惕的信号

| 日期 | RSI | 成交量 | 条件 | 3M 最高 | 3M 最差 |
|------|-----|--------|------|---------|---------|
| 2025-11-14 | 30.17 | 47k (P85.5) | C1 | +2.49% | **-36.18%** |
| 2025-11-21 | 23.12 | 72k (P95.5) | C1+C2 | **+13.89%** | -25.56% |
| 2026-02-02 | 29.23 | 42k (P84.8) | C1 | -0.07% | **-19.58%** |

**教训**：
- 2025-11 月从 14 日到 25 日连续出现 5 个 C1 信号，虽然每个都有 +2%~+14% 的反弹窗口，但回撤深达 -30%+。**持续的 RSI 超卖但没有放量确认，是下跌中继而非底部。**
- 2025-11-21 虽然有 C1+C2 双重信号，但跌势延续，说明在急跌熊市中需要等待放量后的二次确认。

## 重要发现

1. **成交量是最重要的过滤器**：单独 C2 的 28 个信号中包含大量 2024 牛市放量，噪音多；但 C1+C2 组合把信号精准锁定在 7 个真正的底部。
2. **RSI 超卖 + 巨量（C1+C2）是最优组合**：7 个信号全部正收益，平均最高 +28%，最差回撤仅 -7%。
3. **C1 在 2023 年 8 月的表现十分突出**：$25,000-$26,000 区间出现多个连续 C1 信号，3 个月内最高收益全部超过 +40%。
4. **2026 年 2 月的下跌集群**：C1 在 01-31 到 02-24 之间密集出现，但直到 02-05 的巨量日（106k BTC）才确认底部，之后开始反弹。
5. **2026 年 4 月的 C3 信号尚未验证**：2026-04-07 出现 RSI 背离（锚点 2026-02-04），价格新低但 RSI 回升至 59，但数据窗口尚未覆盖 90 日。

## 运行方式

```bash
# 下载数据
uv run -m scripts.download_klines BTCUSDT 1d 2023-06-01

# 查看 DB 状态
uv run -m scripts.inspect .data/crypto/binance-1d.db

# 跑 BTC 底部策略研究
uv run -m research.btc_bottom
```

## 参数说明

| 参数 | 默认值 | 含义 |
|------|--------|------|
| RSI 阈值 | 30 | RSI 低于此值触发 C1 |
| 成交量百分位 | P95 | 2 年窗口内的成交量百分位门槛 |
| 背离时间窗 | 90 天 | C3 寻找 RSI 锚点的回溯窗口 |
| 背离 RSI 锚点 | 35 | 历史锚点的 RSI 需低于此值 |
| RSI 背离差距 | ≥ 15 | 当前 RSI 与历史锚点 RSI 的最小差值 |
| 当前 RSI 下限 | 40 | 触发 C3 时当前 RSI 需 ≥ 此值 |
